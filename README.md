# toolbox-site

Landing page for [notes](https://toolbox.tobiasdossinger.com), one of my personal
CLI tools. The tools themselves live in a separate private repo; this repo only
holds the public page, served by GitHub Pages at toolbox.tobiasdossinger.com.

- `index.html`: the whole page (inline CSS/JS, fonts from Google Fonts)
- `notes-ai-demo.gif` / `.png`: terminal recording of `notes todos --ai`
- `CNAME`: custom domain for GitHub Pages
